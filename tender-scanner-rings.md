# Оценка тендера: сканер-кольца (техническое задание)

Дата оценки: 24.08.2026

## Требования ТЗ (кратко)
- Беспроводное сканер-кольцо, дальность считывания от 10 см, вес с АКБ ≤80 г
- Штрих-коды: 1D (EAN-13, EAN-8), 2D (DataMatrix, UPC-E, Code39)
- Время отклика <1 сек, Bluetooth ≥4.0, связь с телефоном ≥10 м в помещении
- Автономность ≥12–14 ч, заряд ≤2 ч, разъём Type-C/micro-USB без переходников
- Совместимость: Android, Windows, Linux Ubuntu
- Прочность: падение с высоты ≥1,5 м, защита IP65, температура -10°C…+50°C
- Индикация свет+звук+вибро, регулируемое крепление, работа во время зарядки
- Авто-Enter, инверсия, активация сопряжения кнопкой без сканирования ШК
- Опционально: 2 доп. ремешка
